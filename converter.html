🔄 Конвертер песен старый → новый формат

Превращает аккорды из отдельных строк в формат [Аккорд]текст для вашего песенника
📄 1. Старый формат (исходник)

📌 Пример старого формата:

Em
Белый снег, серый лед
Am
На растрескавшейся земле
C
Одеялом из луж

→ аккорды отдельными строками, текст отдельно

✨ 2. Новый формат (аккорды в строке)

✅ Результат — готово для песенника:

[Em]Белый снег, [Am]серый лед
[C]На растрескавшейся земле

Здесь появится преобразованный текст
📁 3. Пакетная обработка (конвертировать несколько файлов сразу)

📌 Как это работает:

1. Выберите один или несколько .txt файлов со старым форматом

2. Конвертер обработает их все и предложит скачать архив с новыми файлами

3. Просто замените старые файлы в папке songs/ на новые

💡 После конвертации просто замените старые файлы в папке songs/ на новые.
Файл songs.csv менять не нужно — названия песен остаются те же.
