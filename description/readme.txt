Структура папок:

text
песенник/
+-- index.html          (этот файл)
L-- songs/
    +-- songs.csv       (список песен)
    +-- Кино - Звезда.txt
    +-- Ария - Беспечный.txt
    L-- ... (другие .txt файлы)



Файл songs/songs.csv (создаёте один раз):

csv
Название,Исполнитель,Файл
Звезда по имени Солнце,Кино,Кино - Звезда.txt
Беспечный ангел,Ария,Ария - Беспечный.txt
Пачка сигарет,Кино,Кино - Пачка сигарет.txt
Nothing Else Matters,Metallica,Metallica - Nothing.txt


Чтобы добавить новую песню:
Открываете songs.csv в Блокноте (или Excel)
Добавляете строку: Название,Исполнитель,имя_файла.txt

Создаете имя_файла.txt в папке songs/ с текстом песни
Обновляете страницу (F5)

Формат текста песни (.txt файл):

text
[Em]Белый снег, [Am]серый лед
[C]На растреска[D]вшейся земле
[Em]Одеялом из [Am]луж накрытый [C]след.

[Припев]
[Em]И мы зна[Am]ем, что так бы[C]ло

Аккорды в квадратных скобках [C] — парсер сам расставит их над словами.
