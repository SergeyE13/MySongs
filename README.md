# 🎸 Песенник

Простой и удобный песенник с аккордами для гитаристов. Работает прямо в браузере, адаптирован для телефона.

**[Открыть песенник](https://sergeye13.github.io/MySongs/)**

---

## ✨ Возможности

### 🎵 Просмотр песен
- Список всех песен с поиском по названию и исполнителю
- Отображение аккордов над словами в тексте песни
- Поддержка сложных аккордов: A7, C7, Dm7, Gm7, F, C, G и других

### 🎼 Транспонирование
- Быстрое изменение тональности на ±1 полутон
- Сброс к оригинальной тональности
- Транспонирование для каждой песни сохраняется в браузере

### ✏️ Редактор песен
- Вход по GitHub-токену (хранится в браузере)
- Редактирование текста и аккордов прямо на сайте
- Автоматическое сохранение правок в браузере
- Сброс к оригинальному тексту

### 📱 Адаптация
- Удобный интерфейс для телефона
- Крупные кнопки для пальцев
- Автоматическое скрытие меню на узких экранах

---

## 🚀 Быстрый старт

1. Откройте [песенник](https://sergeye13.github.io/MySongs/)
2. Выберите песню из списка
3. Используйте кнопки `♭ -1` / `♯ +1` для изменения тональности
4. Для редактирования нажмите кнопку **"✏️ Редактор"** и введите GitHub-токен

## 📝 Формат песен

### Структура файла 
[Куплет 1]

[Dm]Было время — я шёл [Gm]тридцать восемь узлов,
[A7]И свинцовый вал [Dm]резал [A7]форштевень,
[Dm]Как героев встречали [Gm7]моих моряков
[C7]Петроград, [C]Лиепая и [F]Ревель [A7].


### Правила форматирования
- Аккорды пишутся в **квадратных скобках**: `[Am]`
- Аккорды пишутся **в той же строке, что и текст**, перед соответствующим словом
- Используются **только латинские буквы**: `C`, `A`, `D`, `G` и т.д.
- Разделы (Куплет, Припев) пишутся в квадратных скобках отдельной строкой
